# 使用手册

---

## 1. 手机端准备（只做一次）

### 1.1 打开开发者选项

设置 → 关于手机 → 连续点击「版本号」7 次，提示「您已处于开发者模式」。

### 1.2 打开 USB 调试

设置 → 系统 → 开发者选项 → **USB 调试** 打开。

> **小米 / 红米 / HyperOS 用户特别注意**：还要打开 **「USB 调试（安全设置）」**
> （有的版本叫「允许通过 USB 调试模拟点击」）。
> 不开的话能看画面但**点不动**。

### 1.3 首次插线授权

插上数据线后手机会弹「是否允许 USB 调试」，勾选**始终允许**并确定。

如果误点了拒绝：拔插数据线重来，或在开发者选项里「撤销 USB 调试授权」后重新插。

### 1.4 无线调试前置条件（走无线才需要）

- 手机和电脑在**同一局域网**
- 开发者选项 → **无线调试** 打开
- 安卓 11 及以上才有无线调试；低版本走「USB 转无线」方式

## 2. 四种连接方式

### 2.1 USB 直连（最稳、延迟最低）

1. 数据线连接（**必须支持数据传输**，纯充电线不行）
2. 界面「投屏」页 → 点「刷新设备」

> **设备列表旁边三个按钮**
> - **刷新设备**：立刻重新执行 `adb devices`（平时每 4 秒自动刷一次）
> - **删除设备**：把选中的设备从列表里去掉
>   - 网络设备（`IP:端口`）→ 会真的执行 `adb disconnect IP:端口`，之后不再出现
>   - USB 设备 → ADB 命令删不掉（它由数据线连着），程序会说明并**只在列表里隐藏**
> - **显示全部**：恢复被隐藏的设备（隐藏只在本次运行有效，重启程序即恢复）
3. 下拉框选中手机（状态应为**已授权**）
4. 调好参数 → 点「开始投屏」

排查顺序：`adb devices` 空 → 数据线/USB 口/驱动；`no permissions` → udev 规则；
`unauthorized` → 手机上的授权弹窗。

### 2.2 无线 · 配对码（不依赖 mDNS）

> ⚠️ **前提**：`adb pair` 是 platform-tools 30（2020）才有的命令。老发行版源里的
> adb（如 Ubuntu 22.04 的 28.0.2）会报 `adb: unknown command pair`。
> 这种情况请先升级 adb（构建脚本会自动取官方 platform-tools），
> 或改用 **2.4 的「USB 转无线」**（`adb tcpip` / `adb connect` 老版本就有）。

**手机端**：开发者选项 → 无线调试 → **使用配对码配对设备**

屏幕会显示两组信息，**注意它们是两个不同的端口**：

```
配对用的 IP 地址和端口：192.168.1.23:37123    ← 配对端口
WiFi 配对码：123456
```

**界面操作**：

1. 「无线连接」页 → 方式二 → 填配对 IP、配对端口、6 位配对码 → 点**配对**
   - 嫌手抄麻烦可以点**「自动发现配对端口」**（依赖 mDNS，可能失败）
2. 退回手机的无线调试**主页**，看「IP 地址和端口」（这是**连接端口**，与配对端口不同）
3. 回到方式一，填 IP 和连接端口 → 点**连接**
4. 回「投屏」页 → 刷新设备 → 开始投屏

**放弃 mDNS 也能用**——这就是本方式的价值：完全不依赖组播发现。

### 2.3 无线 · 二维码（最省事，需要 mDNS）

**前提**：安卓 11+，且本机 mDNS 可用（校园网客户端隔离会导致失败）。

1. 「无线连接」页 → 方式三 → 点**「生成二维码并配对」**
2. 手机：开发者选项 → 无线调试 → **使用二维码配对设备** → 扫描屏幕上的二维码
3. 程序自动完成：等手机广播 → `adb mdns` 发现配对服务 → `adb pair` → 取连接地址 → 连接
4. 回「投屏」页刷新设备即可

**二维码载荷格式**（程序自动生成，无需你操心）：

```
WIFI:T:ADB;S:<服务名>;P:<密码>;;
```

这是安卓侧要求的 WiFi 配置串格式，不是 JSON。程序里 `P` 字段放的是
`base64(明文密码)`，并会**两种解释都试一遍**，兼容不同安卓实现。

**卡在「正在配对设备」怎么办**：点「mDNS 诊断」按钮，按提示排查；
或直接改用 2.2 的配对码方式。

### 2.4 USB 转无线（所有安卓版本通吃）

先插着线：

1. 「无线连接」页 → 方式一 → 点**「启用无线端口」**（等价 `adb tcpip 5555`，会自动填好手机 IP）
2. 拔掉数据线
3. 点**「连接」**

> `adb tcpip` 的设置**手机重启后失效**，需要重新插线开一次。
> 二维码/配对码方式可以撑过重启（但无线调试开关有时会被系统关掉）。

### 2.5 已配对过的日常连接

配对过一次之后，以后只要：

1. 手机打开无线调试
2. 点「自动发现设备」（mDNS 可用时）或手动 `adb connect IP:端口`
3. 投屏页刷新 → 开始投屏

## 3. 参数逐项说明

| 界面选项 | 对应 scrcpy 参数 | 说明 |
|---|---|---|
| 最大分辨率 | `--max-size <n>` | 长边上限。**无线卡顿时最先调这个**，1024 通常够用 |
| 视频码率 | `--video-bit-rate`（1.x 为 `--bit-rate`） | 8M 起步；无线卡降 4M/2M |
| 投屏时手机息屏 | `--turn-screen-off` | 手机屏幕关掉但继续投屏，省电降温 |
| 保持手机唤醒 | `--stay-awake` | 防止手机休眠导致无线断连 |
| 全屏显示 | `--fullscreen` | 启动即全屏 |
| 窗口置顶 | `--always-on-top` | 窗口始终在最前 |
| 不转发音频 | `--no-audio` | 仅 scrcpy 2.0+ 有效；1.x 会自动忽略并提示 |
| 录屏到文件 | `--record <path>` | 默认 `~/scrcpy-record.mp4` |
| 额外参数 | 原样追加 | 见下表常用参数 |

### 常用额外参数

```
--video-codec h265          用 H.265 编码，同画质省约 30% 带宽（2.0+）
--crop 1080:1080:0:0        裁剪画面
--display-id=1              投第二个屏幕（折叠屏/外接屏）
--window-title 我的手机      自定义窗口标题
--no-control                只看不控
--power-off-on-close        关窗口时让手机锁屏（3.0+）
--audio-codec opus          音频编码（2.0+）
-K / --keyboard=uhid        用真实键盘映射（游戏用）
```

## 4. 窗口快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl` + `H` | 返回（Home） |
| `Ctrl` + `B` | 后退 |
| `Ctrl` + `M` | 多任务 / 最近应用 |
| `Ctrl` + `P` | 电源键（锁屏 / 亮屏） |
| `Ctrl` + `O` | 手机熄屏（保持投屏） |
| `Ctrl` + `Shift` + `O` | 手机亮屏 |
| `Ctrl` + `S` | 截屏保存到电脑 |
| `Ctrl` + `R` | 旋转屏幕 |
| `Ctrl` + `F` | 切换全屏 |
| `Ctrl` + `W` | 关闭窗口 |

鼠标：**左键**=触摸，**右键**=返回，**中键**=主页，**滚轮**=上下滑，
**拖拽文件到窗口**=把文件推到手机。

## 5. 录屏

勾选「录屏到文件」并填路径即可（默认 `~/scrcpy-record.mp4`）。
录制格式由扩展名决定：`.mp4` / `.mkv` / `.m4a`（仅音频）。

想录成固定大小可配合 `--max-size`；录屏时建议关掉「不转发音频」以便带声音。

---

## 6. 多设备

插多台手机时，设备下拉框会列出全部。切换设备前先**停止投屏**，再选另一台。

想同时投屏两台，直接开两个程序实例即可（各自选不同设备）。

## 7. Windows 与 Linux 的差异

| 项目 | Windows | Linux |
|---|---|---|
| scrcpy / adb 来源 | 官方 `scrcpy-win64` 解压包，**自带 adb** | 发行版包 / snap / 源码编译 |
| USB 权限 | 厂商 USB 驱动（设备管理器） | udev 规则（`install-udev.sh`） |
| 程序自动查找位置 | `C:\scrcpy`、`platform-tools`、SDK、下载目录、exe 同目录 | PATH、`/usr/bin`、`/usr/local/bin`、`/snap/bin`、AppRun 包内 |
| 中文字体 | 微软雅黑 | Noto Sans CJK / 文泉驿 |

## 8. 界面里的自助排错入口

| 位置 | 功能 |
|---|---|
| 「投屏」页 · 安装 USB 权限 | Linux 一键提权安装 udev 规则（pkexec） |
| 「无线连接」页 · 自动发现设备 | `adb mdns` 找已配对的无线设备 |
| 「无线连接」页 · 自动发现配对端口 | 找配对服务地址，省得手抄 |
| 「无线连接」页 · mDNS 诊断 | 一键跑 `adb mdns check/services` 并给出中文结论 |
| 「无线连接」页 · 复制二维码内容 | 二维码库缺失时的兜底 |
| 「帮助」页 | 平台相关的安装说明与常见问题 |

遇到问题先看 **运行日志** 区域——scrcpy 的原始终端输出、报错、退出码都在里面。
更多排错见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。
